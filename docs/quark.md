# 夸克分享与后台下载

当前是仅支持 Mac 本机的受限功能，使用你已有的夸克账号，通过夸克官方 CLI 授权。已接入 LIBVIO 夸克分享目录、文件选择、后台队列与整理入库流程，无需另外安装夸克桌面客户端；能否下载仍受官方接口的文件大小限制。

## 当前验证状态

2026-10-25，真实的 206633802 字节视频在获取下载地址时被官方接口拒绝，返回 `23018 / download file size limit[52428800]`，即当前接口的单文件 50 MiB 限制。同一账号刷新权益后重试仍返回该限制。官方发布仓库中仍开放的 [Issue #5：下载大小限制](https://github.com/quark-clouddrive/quarkclouddrive_offical/issues/5) 有相同报错，尚无公布的解决办法。

目前未完成夸克视频的完整真实下载、暂停后续传及自动入库验证。相关代码和单元测试覆盖了这些流程，不能视为已经通过真实下载验收；正常影视大小的文件仍可能在取址阶段被拦截。应用会明确显示限制，不清除当前有效账号，不自动反复重试，也不通过拆分或伪装其他客户端绕过限制。没有证据表明购买会员一定能解除该接口限制。

## 准备和连接

在仓库内执行：

```sh
python3 scripts/quark/prepare-runtime.py --runtime-dir "$PWD/.local/quark-runtime"
```

准备脚本只从夸克官方地址获取固定的 1.0.25 发行包，校验 ZIP 和运行文件 SHA256，不执行上游安装脚本、不安装全局命令。已有同一官方 ZIP 时可使用 `--archive /absolute/path/quarkclouddrive-1.0.25.zip`。

在私密 `.env.macos.local` 添加绝对路径：

```dotenv
QUARK_RUNTIME_DIR=/absolute/path/to/LibreTV/.local/quark-runtime
```

构建并在无活跃下载、缓存任务时重启本机服务。进入「设置 → 点播源 → 夸克网盘 → 登录夸克」，在官方网页登录已有账号并确认授权范围，再回到 LibreTV 点「检查登录」。官方工具使用 Codex 授权渠道，授权页面会显示该渠道。

官方 CLI 只等待约 60 秒。网页已经授权成功，但本机仍显示未连接时，可以在官方授权页复制仍在有效期内的授权码，回到同一设置项点「填写授权码」，输入后点「完成连接」。授权码只填写在 Mac 本机的这个输入框中；应用通过私密标准输入交给官方 CLI，不把它放入系统进程参数、环境变量或公开响应。若提示授权码无效或已过期，再点「登录夸克」获取新的授权。应用不会自动反复弹出登录页。

只在 Mac 启动器的 `127.0.0.1:8899` 私有监听上开放夸克接口；公网密码登录不会获得该功能。服务器和 iPhone 不自动接收 Mac 的夸克凭据。

## 下载流程

LIBVIO 播放页的夸克分享入口打开文件选择器。进入目录并勾选具体视频，确认片名、电影／电视剧、季数与必要的单集编号，点「转存并下载」。仅转存选中文件到平台默认目录下的 `LibreTV/<任务编号>` 文件夹，再从该副本下载到 Mac；转存会占用你的夸克网盘空间。取消本地下载不会自动删除这份网盘副本。

队列绑定入队时的账号指纹和稳定文件 ID。短时下载地址和账号凭据由官方 CLI 管理，不返回浏览器、不写入公开任务响应。转存后按独立任务目录中的名称和大小唯一匹配保存后的文件，不猜测映射、不转存整个分享。

电视剧优先使用明确填写的集数，否则从 `S01E05`、`第05集`、`E05`、`05.mp4` 等文件名识别。无法识别时需单独选择并填写。电影合集批量下载按每个文件名分别命名和识别年份，不把整套影片都归成同一部。

每次目录读取最多展示 400 项，并明确告知是否还有条目。目录和显式选择缓存在本机；加入队列会重新验证本机缓存和账号绑定。官方 CLI 串行运行，正在下载时读取新分享可能提示忙，可以先暂停下载；已读取的文件仍可加入队列。

## 暂停、续传与离线

- 后台任务有「暂停」「继续」「取消」。暂停保留工作目录、已写入的完整数据块、官方 SDK 断点和入库暂存；取消清除该任务本地临时数据，保留已转存的网盘副本及已入库影片。
- 夸克下载正常暂停时向官方 CLI 发送 SIGINT，等待它保存块进度，再通过同一 SDK 记录、同一输出目录续传。服务正常停止也执行此流程。断电、强杀或官方未留下有效断点时，未完成的部分可能需要重新下载；未承诺这些情况下都能从最后一个字节恢复。
- 原有 HLS 下载复用已完整保存的分片。原有普通 MP4 下载仍不支持 HTTP Range 字节续传；不能把夸克的续传能力推广为所有来源都支持。
- 关闭网页或退出浏览器不影响本机后台下载；Mac 仍需开机、保持唤醒和联网。Mac 关机或睡眠时不会继续下载。下载完成并入库的文件可断网播放。
- Mac 关机后继续下载需要任务运行在在线服务器。当前夸克接入仅在 Mac，本轮没有把账号或夸克任务部署到服务器。
- 当前未提供磁力、BT 或任意 HTTP 链接的云端离线下载。分享转存、服务器后台下载和本地离线观看是不同功能。

网盘容量、文件大小、访问权限、速度及使用额度仍由夸克决定。支持下载不代表全部文件都能网页播放；MKV 或特殊音轨可能在 MP4 整理时失败，任务会保留明确错误。

## 私密状态

运行时、令牌、下载断点和目录缓存均在 `.local/quark-runtime`，不提交 Git。子进程仅重定向自身 `os.homedir()` 到专用私密目录，不修改用户 `HOME`，不迁移日常账号资料。不向上游发送原始聊天输入，也不开放任意 CLI 命令或自定义 Cookie／请求头 API。

本地清理按账号指纹、保存后的文件 ID 和记录 ID 严格绑定；可以在断网或登录失效时删除自己的 SDK 断点，保留其他账号、其他任务及网盘文件。

官方依据：[夸克网盘 Skill 帮助](https://www.quark.cn/documents/help/quark-drive-skill)、[官方发布仓库](https://github.com/quark-clouddrive/quarkclouddrive_offical)。当前集成使用固定运行工具，不将第三方代理提示词安装为全局技能。
