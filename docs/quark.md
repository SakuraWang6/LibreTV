# 夸克分享接入

这是仅在 Mac 本机免登录模式下开放的受限功能，通过固定版本的夸克官方 CLI 连接已有账号，无需安装夸克桌面客户端。服务器和 iPhone 不接收 Mac 的夸克凭据。

## 当前限制

2026-10-25 的真实验证已完成授权、LIBVIO 分享目录读取、文件选择和单文件转存；一个 206,633,802 字节视频在获取下载地址时被拒绝，返回 `download file size limit[52428800]`。刷新权益后重试仍被当前接口的 **50 MiB 单文件限制**挡住。官方仓库的 [Issue #5](https://github.com/quark-clouddrive/quarkclouddrive_offical/issues/5) 有相同报告，未公布解除方法。

**真实视频完整下载、暂停后块续传、自动入库尚未完成验收。** 实现和自动测试覆盖了这些流程，但不能据此宣称常规电影下载已经可用，也没有证据表明购买会员一定解除这个接口限制。

## 准备与授权

先按 [Mac 说明](macos.md) 配置本机服务，并启用 `LOCAL_AUTH_BYPASS='true'`。在仓库中准备独立运行目录：

```sh
python3 scripts/quark/prepare-runtime.py --runtime-dir "$PWD/.local/quark-runtime"
```

脚本下载固定的 1.0.25 官方发行包，校验 ZIP 与运行文件 SHA256，只提取所需工具；不执行上游安装脚本、不安装全局命令。已有同一发行包时可追加 `--archive /absolute/path/quarkclouddrive-1.0.25.zip`。

在 `.env.macos.local` 添加绝对路径：

```sh
QUARK_RUNTIME_DIR='/absolute/path/to/LibreTV/.local/quark-runtime'
```

在无活跃任务时重启服务，然后：

1. 打开「设置 → 点播源 → 夸克网盘 → 登录夸克」。
2. 在官方网页登录已有账号，亲自确认授权范围。官方工具使用 Codex 渠道，页面会显示该渠道。
3. 回到 LibreTV 点「检查登录」。

官方工具只等待约 60 秒。若网页已经授权、本机仍未连接，在官方页面复制仍有效的授权码，回 LibreTV 点「填写授权码 → 完成连接」。过期后重新发起登录。授权码通过私密标准输入交给子进程，不进入系统进程参数、环境变量或公开响应。

## 分享选择与任务

LIBVIO 播放页点「夸克下载」，进入目录、勾选具体视频，确认片名、电影/电视剧、季数和必要的单集编号，再点「转存并下载」。

- 仅转存选中文件到平台默认目录下的 `LibreTV/<任务编号>`，占用网盘空间。取消本地任务保留这份网盘副本。
- 电视剧可从 `S01E05`、`第05集`、`E05`、`05.mp4` 等文件名识别集数；无法识别时单独选择并填写。电影合集按每个文件分别命名和识别年份。
- 每个目录最多显示 400 项，并提示是否还有更多。目录缓存在本机，入队时重新检查缓存与账号绑定。
- 官方 CLI 串行执行；正在下载时读取新目录可能提示忙，可先暂停任务。已读取的文件仍可入队。
- 下载受账号容量、分享权限、接口额度和编码支持限制。失败任务显示具体错误，不自动反复重试。

## 暂停与离线的边界

后台任务提供暂停、继续、取消。实现会在正常暂停或停止服务时向 CLI 发送 SIGINT，等待官方 SDK 保存块断点，再使用同一记录和输出目录继续。断电、强杀或无有效断点时，未完成部分可能重下；这部分仍待真实下载验收。

关闭网页不停止本机后台任务；Mac 仍须开机、唤醒、联网。关机或睡眠不会继续下载，任务也不会自动转到服务器。已经完整入库的视频可断网播放。

HLS 后台下载只能复用完整分片，普通 MP4 来源尚无 HTTP Range 字节续传。当前未提供磁力、BT 或任意 HTTP 链接的云端离线下载。

## 私密资料与清理

运行工具、令牌、目录缓存和 SDK 断点位于 `.local/quark-runtime/`，不提交 Git。子进程使用独立私密目录，不迁移日常浏览器资料，也不向上游发送原始聊天输入。短时下载地址与凭据由官方工具管理，不返回浏览器任务列表。

取消只清理该任务的本地临时数据和匹配断点，保留网盘副本及已入库影片。不要把整个 `.local/quark-runtime/` 当作普通缓存删除；重装工具前先等待所有夸克操作结束，保留授权与断点目录。

配置入口见 [配置说明](configuration.md)。上游资料：[官方帮助](https://www.quark.cn/documents/help/quark-drive-skill)、[官方发布仓库](https://github.com/quark-clouddrive/quarkclouddrive_offical)。本项目只使用固定运行工具，不安装第三方代理提示词为全局技能。
