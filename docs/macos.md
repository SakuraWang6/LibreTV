# Mac 本地运行

Mac 启动器固定监听 `http://127.0.0.1:8899`，片库入口为 `/library`。关闭网页不会停止后台服务；后台下载和服务器缓存仍需要 Mac 开机、保持唤醒并联网。

## 首次准备

需要 Node.js、npm 和 FFmpeg。启动器要求 Node.js 18.18 或以上；FFmpeg 用于整理后台下载的视频。安装好这些工具后，在仓库目录执行：

```sh
npm ci
cp -n .env.macos.example .env.macos.local
chmod 600 .env.macos.local
npm run build
```

编辑 `.env.macos.local`，至少设置自己的 `PASSWORD`。启动器会用 Bash 加载该文件，密码、JSON 和带空格的路径使用单引号；只编辑可信内容。找不到 Node 或 FFmpeg 时，填写 `NODE_BINARY`、`FFMPEG_PATH` 的绝对路径。其他变量见 [配置说明](configuration.md)。

媒体目录索引需要启用本机免登录：添加 `LOCAL_AUTH_BYPASS='true'`，仍保留 `PASSWORD`。该模式仅由 Mac 启动器为 `127.0.0.1:8899` 启用，不能同时配置 `PUBLIC_ORIGIN`，也不能将这个本机入口通过反代或端口转发公开。公网部署使用独立配置和访问密码。

## 启动、停止与自启

```sh
./scripts/macos/start.command
./scripts/macos/stop.command
```

启动后打开 `http://127.0.0.1:8899/library`，也可双击仓库中的 `LibreTV.app`（显示名「光影」）。App 会启动服务，再用独立 Chrome 窗口打开片库；未安装 Chrome 时使用默认浏览器。App 必须与仓库保持当前相对位置。

启动器管理网页、下载进程，以及按配置启用的服务器同步。重复启动会复用现有实例；端口被其他程序占用时会报错。关闭网页、App 窗口或终端不会停止服务。

登录 Mac 后自动启动：

```sh
./scripts/macos/install-launch-agent.command
```

取消自启并停止服务：

```sh
./scripts/macos/uninstall-launch-agent.command
```

自启项为 `~/Library/LaunchAgents/io.libretv.local.plist`。运行 `stop.command` 只停止当前登录会话中的任务；已安装的自启在下次登录时仍会生效。移动仓库前，先在旧位置卸载自启，再在新位置安装。

## 片库与后台下载

- 在播放页点「下载本集」，确认入队后可关闭窗口。下载管理支持暂停、继续、取消和失败重试；完整下载、整理并入库后才会出现在片库。移除下载记录保留已经入库的视频。
- HLS 下载复用完整分片；普通 MP4 来源尚不支持 HTTP Range 字节续传。暂停不能保证所有来源都从最后一个字节继续。
- 启用上述本机模式后，「导入视频」用于添加媒体目录：连接硬盘后选择文件夹，或粘贴目录路径，扫描并选中影片加入片库。视频保留在原目录，Mac 只保存索引、海报、简介和进度，不复制视频。当前识别 MP4、M4V、WebM、MOV；能否直接播放还取决于编码。
- 加入片库前会按文件名识别的信息，从已启用的普通点播源匹配海报与简介。年份或同名作品无法确认、网络不可用时，仍可按原信息建立索引；之后可在「补全资料」修正匹配片名、年份后重试。
- 已保存的海报和进度可离线使用；库内视频或仍连接的硬盘原片可以断开外网播放。Mac 和本地服务仍须运行，文件编码也须被网页播放器支持。

默认库目录是 `.local/library/`，保存受管理的视频、资料与索引；引用的原片留在登记目录。修改 `LOCAL_LIBRARY_DIR` 前先停止服务，再完整迁移库目录，包括隐藏的 `.libretv`。备份该库不会复制外部原片，原片须单独备份。后台任务在提交时所在的服务执行，不会自动从 Mac 转移到服务器。

片库中的「补全资料」可处理缺少海报或简介的影片，并允许修正匹配片名、年份后重试。补资料保留视频文件、编号和观看进度，海报缓存到当前片库供离线使用。已有的简介、真实海报和电视剧季集不自动覆盖。

目录索引只在 Mac 启动器的本机免登录模式开放。硬盘拔出后，片目和资料仍保留，视频显示不可用；重新接入同一硬盘后可继续。目录注册与播放读取均核对卷标识和文件身份，不会在硬盘断开时创建替代目录，也不会删除或改写外部原片。原路径的影片被替换或修改后，重新扫描并选择加入以验证新文件；移动或改名不会自动追踪。

服务器或未启用上述本机模式的网页，导入仍是上传复制到当前服务的片库，需要在上传完成前保持窗口打开；上传对话框可确认片名、年份、分类、季和集。Mac 已登记的硬盘目录不会自动传到服务器；手机不能仅凭这份索引读取 Mac 外接盘。

左右方向键每次快进或快退 5 秒，按住不连续累加跳转。播放中长按画面或按住右方向键约 350 毫秒可临时 2 倍速，松开或切走页面后恢复原速；进度条仍可拖动。鼠标悬停在进度条上会显示对应时间的画面，点击或拖动才改变播放位置。片库按需生成并缓存小图；在线源无法提供可读取的画面时只显示时间。播放中停止操作约 2.5 秒会隐藏控制栏和画面内鼠标，移动后恢复；暂停、拖动和键盘选择控件时保持显示。片库首次悬停需要提取缩略图，连续移动时会保留一个提帧任务并缓存，再处理当前停留的位置。

## 服务器片库与跨设备观看

服务器部署见 [服务器说明](server.md)。在 Mac 私有配置中设置：

```sh
LIBRARY_SERVER_URL='https://media.example.com'
LIBRARY_SERVER_PASSWORD='your-private-server-password'
```

重启本机服务后，可在「服务器片库」查看目录，对影片或具体剧集点「保存到本地」。缓存完成后，本地副本可离线观看；不会自动复制整库，也不会上传 Mac 独立导入的视频。

配对的服务器影片和 Mac 离线副本会同步观看进度。只有一端有新进度时，联网后自动同步；两端都变化时，选择「使用 Mac 进度」或「使用服务器进度」。原搜索播放页 `/watch` 的历史仍按浏览器保存，独立导入的同名文件不会自动配对。

可设置 `LIBRARY_SERVER_MEDIA_TRANSPORT='curl'`，使用 Mac 自带 curl 传输服务器视频 Range 分块；目录、登录和进度仍使用 Node。可选代理只影响同步进程，具体配置与版本条件见 [配置说明](configuration.md)。分块会随实际速度调整，速度上限仍取决于网络与服务器出口带宽。

iPhone / iPad 联网时直接打开服务器 `/library`。离线前点「保存视频到设备」，完整保存到“文件”或导入 VLC；这些外部播放器的进度不会回传光影。当前不提供手机整站离线，也不保证退出 Safari 后大文件继续下载。

## 更新与排查

在没有活跃下载、缓存或导入任务时停止服务，更新代码，按需更新依赖并构建，再启动：

```sh
./scripts/macos/stop.command
npm ci
npm run build
./scripts/macos/start.command
```

| 位置 | 用途 |
| --- | --- |
| `.env.macos.local` | 私有配置，Git 忽略 |
| `.local/library/` | 默认片库、进度、下载队列及同步映射 |
| `.local/browser-profile/` | 光影独立窗口的浏览器资料 |
| `.local/LibreTV.log` | 服务日志 |
| `.local/server.json` | 启动器运行记录 |

启动失败先检查日志、配置密码、Node/FFmpeg 路径、生产构建及端口占用。下载管理提示后台未连接时检查同一日志；片库、配置和浏览器资料不属于可随意删除的缓存。开发与清理规则见 [开发说明](development.md)。
